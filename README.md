# 📘 Lab1
## Криптографические методы

---

## 📌 О проекте

Проект **Lab1** содержит реализации двух классических методов шифрования:

- 🔲 **Метод поворотной решётки**
- 🔤 **Метод Вижнера**

Каждый метод реализован как отдельное десктопное приложение на языке `Go`
с графическим интерфейсом и поддержкой работы с текстовыми файлами.

---

## 📁 Структура проекта

```
Lab1/
├── метод решетки/
│   ├── проект/      # Исходный код приложения
│   ├── exe/         # Скомпилированный исполняемый файл
│   └── txt/         # Тестовые текстовые файлы
│
├── метод вижнера/
│   ├── проект/      # Исходный код приложения
│   ├── exe/         # Скомпилированный исполняемый файл
│   └── txt/         # Тестовые текстовые файлы
│
└── docx/            # Отчет по лабораторной работе
```

---

# 🔲 Метод поворотной решётки

## 📁 Структура проекта

`main.go`

`app.go`

`frontend/App.jsx`


### 📌 Назначение файлов

- `main.go` — точка входа в приложение  
- `app.go` — основная логика (шифрование, дешифрование)  
- `frontend/App.jsx` — графический интерфейс  

---

## 🔐 Где реализована основная логика

Алгоритмы находятся в файле `app.go`.

### Реализованные методы

| Метод | Назначение |
|--------|------------|
| `Encrypt(str string)` | Шифрование текста методом решётки |
| `Decrypt(str string)` | Дешифрование текста |
| `speenMatrix(matrix *[SIZE][SIZE]byte)` | Поворот матрицы на 90° |

---

# 🔤 Метод Вижнера

## 📁 Структура проекта

`main.go`

`app.go`

`frontend/App.jsx`


### 📌 Назначение файлов

- `main.go` — точка входа  
- `app.go` — реализация алгоритма  
- `frontend/App.jsx` — графический интерфейс  

---

## 🔐 Где реализована основная логика

Алгоритм полностью реализован в файле `app.go`.

### Реализованные методы

| Метод | Назначение |
|--------|------------|
| `Encrypt(text, key)` | Шифрование методом Вижнера |
| `Decrypt(text, key)` | Дешифрование методом Вижнера |

---

## ✅ Требования

- Используются только английские буквы `A–Z`
- Для метода Вижнера обязательно наличие ключевого слова

---

## 🛠 Сборка проекта

В папке `проект` выполнить:

go build
