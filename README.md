## 📌 О проекте

Проект tiLAB_1 представляет собой десктопное приложение на языке Go, объединяющее реализацию двух классических методов шифрования:

🔲 Метод поворотной решётки

🔤 Метод Вижнера

---

## 📁 Структура проекта

```
tiLAB_1/
├── fronte/                   # Директория фронтенда (графический интерфейс)
│   └── src/
│       └── App.jsx           # Основной компонент интерфейса
│
├── TI_1.docx                 # Отчет по лабораторной
│
├──/txt                        # Тестовые текстовые файлы
│

├── main.go                    # Точка входа в приложение
└── README.md                  # Документация проекта
```

---
### 📌 Назначение файлов

`main.go` — инициализация и запуск приложения, связывание бэкенда и фронтенда.

`app.go` — реализации алгоритмов шифрования.

`fronte/src/App.jsx` — графический интерфейс пользователя.

`txt/` —  тестовые текстовых файлов.

## 🔐 Реализованные алгоритмы (файл app.go)

В файле `app.go` собрана вся логика работы с шифрами.

---

# 1. Метод поворотной решётки

Реализованы функции для работы с квадратной матрицей-решеткой.

Функция	Назначение

`EncryptM(str string)`	Шифрование текста методом поворотной решётки

`DecryptM(str string)`	Дешифрование текста, зашифрованного решёткой

`speenMatrix(matrix *[SIZE][SIZE]byte)`	Вспомогательная функция для поворота матрицы на 90°

---

# 2. Метод Вижнера

Реализованы функции для шифрования с использованием ключевого слова.

Функция	Назначение

`EncryptV(text, key string)`	Шифрование текста методом Вижнера

`DecryptV(text, key string)`	Дешифрование текста методом Вижнера


## ✅ Требования

- Используются  английские буквы `A–Z` для метода поворота решетки
  
- Используются  русские буквы `А–Я` для метода Вижнера
  
- Для метода Вижнера обязательно наличие ключевого слова
